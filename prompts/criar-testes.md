# Prompt — Criar Testes

Objetivo: ampliar a segurança do sistema com testes automatizados.

Contexto:
- Identifique o componente ou regra a ser testada.
- Descreva se o foco é unitário, integração ou regressão.

Instruções:
1. Isolar o cenário de teste.
2. Definir resultado esperado com clareza.
3. Cobrir casos críticos e borda.
4. Garantir que o teste represente o comportamento real do sistema.
