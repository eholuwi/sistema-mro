# Prompt — Criar Módulo

Objetivo: criar um novo módulo com responsabilidade clara dentro da arquitetura do projeto.

Contexto:
- Defina o contexto do módulo: estoque, compras, dashboard, relatório ou dados.
- Indique se ele deve depender de services, controllers, repositories ou database.

Instruções:
1. Identificar responsabilidade única do módulo.
2. Definir interfaces e dependências.
3. Implementar com estrutura limpa e reutilizável.
4. Registrar testes e documentação mínima.
