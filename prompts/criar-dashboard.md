# Prompt — Criar Dashboard

Objetivo: criar ou evoluir dashboards do sistema MRO com foco em decisão operativa.

Contexto:
- Descreva a audiência: compras, almoxarifado, gestão ou executivo.
- Indique as métricas e os filtros esperados.

Instruções:
1. Definir KPI e visão de negócio.
2. Estruturar os componentes gráficos e os dados de origem.
3. Implementar com foco em legibilidade e interpretação.
4. Validar a consistência dos cálculos.
