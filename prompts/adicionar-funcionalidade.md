# Prompt — Adicionar Funcionalidade

Objetivo: incorporar uma nova funcionalidade ao Sistema MRO mantendo compatibilidade e qualidade.

Contexto:
- Descreva a necessidade operacional.
- Indique os módulos afetados.
- Explique se a mudança altera regra de negócio, UI ou banco.

Instruções:
1. Entender o problema e o impacto.
2. Mapear arquivos e componentes envolvidos.
3. Propor uma solução incremental.
4. Implementar com testes e documentação.
5. Validar compatibilidade com dados existentes.
