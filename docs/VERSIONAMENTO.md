# Versionamento e Release

## Padrão

- Major: mudanças incompatíveis ou reestruturação profunda.
- Minor: nova funcionalidade compatível.
- Patch: correção de bug ou ajuste pequeno.

## Convenção

- Formato: vX.Y.Z
- Exemplo: v4.6.0

## Processo

1. Atualizar changelog.
2. Registrar impacto técnico e operacional.
3. Validar testes e compatibilidade.
4. Liberar versão com contexto claro.
