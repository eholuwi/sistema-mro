# Skill — Release

## Objetivo

Organizar a entrega de versões com versionamento, changelog e validação.

## Quando usar

- Antes de publicar ou consolidar uma new release.
- Para preparar uma versão estável do sistema.

## Entrada

- Mudanças concluídas.
- Alterações relevantes e impacto.

## Saída

- Versionamento semântico aplicado.
- Changelog e documentação atualizados.
- Checklist de release concluído.
