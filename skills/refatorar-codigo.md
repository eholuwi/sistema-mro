# Skill — Refatorar Código

## Objetivo

Melhorar legibilidade, modularização e manutenção sem alterar comportamento.

## Quando usar

- Há duplicação de lógica.
- Um módulo ficou muito complexo.
- Há necessidade de reorganizar responsabilidades.

## Entrada

- Código alvo.
- Padrões de qualidade desejados.

## Saída

- Código reorganizado.
- Menor acoplamento.
- Testes preservados ou ajustados.
