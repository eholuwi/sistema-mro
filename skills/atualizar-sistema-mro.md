# Skill — Atualizar Sistema MRO

## Objetivo

Aplicar mudanças de forma segura e compatível ao Sistema MRO.

## Quando usar

- Quando houver nova funcionalidade ou melhoria.
- Quando for necessário corrigir um bug.
- Quando houver refatoração ou mudança de regra operacional.

## Entrada

- Descrição do problema.
- Contexto operacional.
- Módulos afetados.

## Saída

- Plano de implementação.
- Impacto previsto.
- Validação e documentação.

## Passo a passo

1. Compreender o problema e os dados envolvidos.
2. Identificar módulos afetados.
3. Propor solução sem quebrar compatibilidade.
4. Implementar incrementalmente.
5. Validar testes, sintaxe e comportamento.
6. Atualizar changelog e documentação.
