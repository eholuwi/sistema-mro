# Skill — Changelog

## Objetivo

Registrar mudanças, versões, impacto e evolução do projeto de forma auditável.

## Quando usar

- Ao fechar uma entrega.
- Ao liberar uma versão ou hotfix.

## Entrada

- Resumo das mudanças.
- Arquivos alterados.
- Impacto e validação.

## Saída

- Arquivo de changelog versionado.
- Resumo claro para histórico do projeto.
