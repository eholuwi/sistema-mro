# Skill — Criar Dashboard

## Objetivo

Criar ou evoluir dashboards operacionais com foco em decisão e clareza.

## Quando usar

- Para apresentar KPIs de estoque, compras ou cobertura.
- Para facilitar acompanhamento do negócio.

## Entrada

- Público-alvo.
- Métricas e filtros esperados.

## Saída

- Dashboard implementado ou refinado.
- Dados conectados às fontes corretas.
- Estrutura reutilizável.
