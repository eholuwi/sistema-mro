# Skill — Banco de Dados

## Objetivo

Gerenciar schema, migrações, integridade e backup do banco SQLite do sistema MRO.

## Quando usar

- Ao alterar tabelas, índices ou regras de persistência.
- Ao criar ou ajustar importações e logs.

## Entrada

- Requisitos de dados.
- Estratégia de migração.
- Impacto operacional esperado.

## Saída

- Esquema ajustado com segurança.
- Migração documentada.
- Backup e validação preservados.
