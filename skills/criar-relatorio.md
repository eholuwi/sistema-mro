# Skill — Criar Relatório

## Objetivo

Gerar relatórios automatizados com foco em clareza, rastreabilidade e exportação.

## Quando usar

- Para consolidar dados por item, SC, fornecedor ou período.
- Para apoiar auditoria e tomada de decisão.

## Entrada

- Critério de filtro.
- Estrutura desejada para o relatório.
- Formato de saída.

## Saída

- Relatório implementado.
- Dados consistentes e bem formatados.
- Exportação ou exibição adequada.
