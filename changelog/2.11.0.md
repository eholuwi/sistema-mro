🎯 Resumo Executivo
Foco em **adoção e usabilidade**. Chega a **Central de Ajuda** com guias passo-a-passo para
as duas personas reais — **Assistente de Materiais** (almoxarife) e **Comprador** —
consolidando o **Feedback/Backlog** que já existia numa única página. E o app ganha **tema
claro/escuro consistente**: antes o visual dark ficava preso por CSS `!important`; agora o
app **acompanha o tema ativo** do Streamlit (☰ → Settings → Theme), com gráficos, menu e
cores adaptando automaticamente. Nada sobrescreve a base do Sr. Neidson.

🆕 Novidades

❓ Central de Ajuda (consolida a antiga página "Feedback")
- Uma página com **4 abas**: **📖 Guia do Assistente de Materiais** (dar baixa/Requisição,
  Receber com conversão de unidades, contagem física, Ficha 360, leitura dos status
  🔴🟡🟢⚪), **🛒 Guia do Comprador** (Assistente de Reposição "Comprar até"/SCs agrupadas,
  Compras/Fornecedores/cotação, curadoria de conversão, Padrão de Demanda/XYZ, importar
  Relatório de SCs), **✍️ Enviar Feedback** e **🗂️ Backlog**.
- O **Feedback/Backlog** é o mesmo de antes (registro, filtros, atualização de status/
  prioridade, export CSV) — apenas migrou para dentro da Central de Ajuda. O item de menu
  "Feedback" virou **"❓ Ajuda"** (ícone de interrogação), deixando a navegação mais enxuta.

🎨 Tema claro/escuro (nativo)
- O app agora **lê o tema ativo** (`st.context.theme`) e **se adapta**: CSS global, `option_menu`
  e o gráfico Plotly (Curva ABC) mudam entre claro e escuro. Os gráficos nativos
  (`st.bar_chart`/`st.line_chart`) já acompanhavam.
- **Como trocar:** menu **☰** (canto superior direito) → **Settings** → **Theme** (Light /
  Dark / Use system). A preferência é lembrada pelo navegador. **Configurações** ganhou a
  seção **🎨 Aparência** mostrando o tema detectado + instruções; a **Central de Ajuda** também
  explica.
- **`.streamlit/config.toml`** novo define a identidade da marca (laranja `#F36F21`, base dark
  padrão), tornando o menu Light/Dark/Custom consistente.

🗄️ Arquitetura
- **Sem migração / sem DDL.** Tema via config + `st.context` (persiste por navegador);
  Feedback já tinha tabela e funções.
- Novo módulo `services/tema.py` — `paleta(tipo)` **pura** (sem importar streamlit, testável):
  ponto único de verdade de cores para claro/escuro (gráficos, menu, painéis) + o dicionário
  de tokens do CSS.
- `services/styles.py` reescrito para ser **theme-aware**: só o bloco `:root` é gerado da
  paleta; todo o CSS usa `var(--…)`, então a mesma folha serve para os dois temas (antes o
  dark ficava travado por `!important`).
- `app.py`: `tema_atual()` (defensivo → 'dark' se indisponível) e `PAL = paleta(tema_atual())`
  no topo; `option_menu`, o gráfico ABC e o card inline de disponibilidade passam a usar `PAL`.
