🎯 Resumo Executivo
Segunda fase do redesign de explicabilidade: **qualquer número/gráfico é clicável e abre os dados que o compõem**.
Implementa um framework reutilizável (_ajuda_popover, _card_clicavel, _dialog_drill_down) que permite expandir a
explicabilidade para todas as telas (KPI Mensal, Saldo, Ficha, Movimentação) nas fases seguintes.

🧠 Framework de Explicabilidade & Drill-down
- **AJUDA_DADOS** (services/ajuda_conteudo.py): Registro central de textos "o que é · para que serve · como é feito"
  para cada métrica (itens_em_aberto, dist_ok, cobertura_dias, entradas_saidas, etc.).
- **Helpers novos em app.py**:
  - `_ajuda_popover(titulo, chave_ajuda)`: Renderiza título + popover "?" com a explicação. Reutilizável em títulos/cards.
  - `_card_clicavel(label, valor, chave_ajuda, rows_provider, delta)`: Métrica com "?" + help + botão "Detalhes"
    que abre o dialog (via session_state).
  - `_dialog_drill_down(df, titulo)`: Dialog com tabela, busca em tempo real, ordenação e download CSV.
- **Provedores em services/drill_down.py**:
  - `rows_itens_em_aberto()`: Painel de prioridades (SCs abertas, aging).
  - `rows_fornecedores_aberto()`: Top fornecedores por valor.
  - `rows_setores_demanda_aberta()`: Setores com demanda em aberto.
  - `rows_dist_status(status)`: Itens filtrados por status (ok/atenção/crítico).
  - `rows_top_consumo(dias, limite)`: Top N itens por consumo real.
  - `rows_entradas_saidas(periodo)`: Histórico de movimentações por período.
  - `rows_cobertura_faixa(faixa)`: Itens filtrados por faixa de cobertura.

📊 Integração em Dashboards (MVP)
- **Dashboard Comprador** (`_render_dash_compras_mro`):
  - Dialog "Itens em Aberto" (clicável, com session_state).
  - Exemplo funcional pronto para expansão: Fornecedores, Setores.
- **Dashboard Almoxarifado** (próximo passo):
  - Dialog "Distribuição por Status".
  - Dialog "Cobertura (dias)".
  - Dialog "Top 10 Consumo".

**Padrão reutilizável** — Para adicionar um novo drill-down em qualquer métrica:
1. Criar a função `rows_novo_tipo()` em services/drill_down.py.
2. Adicionar a entrada em AJUDA_DADOS.
3. Usar `_card_clicavel()` ou adicionar a verificação em session_state + `with st.dialog(): _dialog_drill_down(rows_novo_tipo())`.
