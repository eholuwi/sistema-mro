CHANGELOG — MRO Inventus Power v2.0.2
Data de Lançamento: 14/05/2026
Tipo de Release: Feature / Refatoração Operacional
Status: ✅ Estável | ✅ Testado | ✅ Compatível
🎯 Resumo Executivo
A versão 2.0.2 foca na agilidade e precisão do inventário físico. O campo rígido de "Caixa/ID" foi substituído por um campo de observação livre, permitindo anotações operacionais rápidas. Além disso, foi corrigida uma falha crítica de auditoria onde itens com estoque zerado não geravam histórico ao terem apenas seu local ou observação alterados. A UI/UX da tabela principal foi ajustada para melhor compactação visual.
🆕 Novas Funcionalidades
📝 Observação de Inventário (Texto Livre)
Substituição do st.selectbox "Caixa/ID (2ª Locação)" por st.text_input. Agora o operador pode registrar inconsistências físicas rapidamente (ex: "material danificado", "sem etiqueta", "caixa avariada").
🔍 Conferência de Metadados no Histórico
Itens com estoque 0 que têm alteração de Local ou Observação agora geram um registro de auditoria na tabela movimentacoes (tipo: entrada, quantidade: 0.0), garantindo rastreabilidade completa sem impactar o saldo físico.
🛠️ Melhorias & Otimizações
📐 Altura Dinâmica da Tabela (Max 320px)
A tabela principal do inventário agora calcula altura_tabela = min(40 + (num_linhas * 35), 320). Mantém a visualização compacta, evita rolagem excessiva e adapta-se automaticamente aos filtros aplicados.
🛡️ Tratamento Seguro deNonee0** Correção de possíveisTypeErrorem comparações de status (estoque_minimo <= 0) e na lógica de validação de saída quandoquantidade == 0`.
`💡 Placeholder Educativo**
Adicionado exemplo claro no campo de observação para padronizar a entrada de dados e reduzir erros de digitação.
📊 Exportação & Dados
📥 Excel Atualizado
A função exportar_inventario_df() agora inclui e renomeia corretamente a coluna caixa_identificacao para "Obs. Inventário" no arquivo final.
🔄 Compatibilidade com Dados Legados
Registros antigos no campo "Caixa/ID" são preservados e exibidos como observações históricas. Nenhuma perda de dados ocorreu.
